# 分块翻译规则卡（完整规则，逐条执行）

## 输出格式

- 只输出 `@@@SEG nnn@@@` 标记和对应译文，段数、编号、顺序与输入完全一致。
- 每段译文写成一行，不要把一段拆成多行。
- 不要输出 `###` 元信息行，不要输出解释、空段、代码围栏、Markdown 加粗或列表符号。
- 文件标题按约定翻译：`chapter-1` → `第 1 章`，`part-1` → `第 1 部分`，
  `preface` → `前言`，`index` → `索引`，`contents` → `目录`。

## 占位符（最关键，绝对不能改坏）

- 形如 `⟦0⟧`、`⟦1⟧`、`⟦/0⟧` 的记号是行内排版标记，代表原文里的链接、加粗、编号等。
- 占位符编号是**每段独立**的：不同段都可以从 `⟦0⟧` 开始，跨段出现相同编号是正常的。
  不要跨段比较编号，也不要为了“全局唯一”改编号。
- 成对占位符 `⟦n⟧ …… ⟦/n⟧`：中间的英文必须翻译，两个标记都保留、顺序不变。
- 单独占位符 `⟦n⟧`：代表代码、函数名、变量名、路径、命令、图片等，原样保留，不要翻译。
- 原文只有 `⟦n⟧` 而没有配对的 `⟦/n⟧` 时，它就是单独标记：只保留这一个，
  绝对不要补 `⟦/n⟧`。段首、图注、表注最常见这种情况；原文没有的标记也不要自己加。
- 不得新增、删除、合并、拆分、改写任何占位符（包括写成 `[1]`）。
- 允许为了中文语序在句子内移动占位符，但配对关系不能变。

## 不翻译的段落

- 整段是代码、命令、日志、清单输出、纯英文示例、人名/机构/地址列表：原样抄回，
  并在该段内单独写一行 `@@@VERBATIM@@@`（放在段首或段尾都可以）。标记行本身不算正文。
- 句子中间的代码、命令、API 名称、库名、类名、函数名、参数名、文件名、
  URL：保留英文，句子照常翻译。

## 译文要求

- 通俗、流畅、技术准确，像一位有经验的工程师用中文给同事讲课。
- 长句按中文习惯拆分或重组，不丢信息，也不添加原文没有的内容。
- 保留原文的举例、类比和幽默感；「you」用「你」，「we」用「我们」。
- 术语按本块术语表；首次出现写「中文（English）」，之后只用中文。
- 作者、机构、地址等元数据可以保留英文原名；正文中的人名、地名首次出现音译并附原文。
- 中文句子使用全角标点；数字、英文、代码、URL 内部保持半角。
- 中英文之间加一个半角空格；全角标点与英文相邻时不加空格。
- 编号：`Listing 4.1` → `清单 4.1`，`Figure 4.1` → `图 4.1`，
  `Table 2.1` → `表 2.1`，`chapter 4` → `第 4 章`，`appendix A` → `附录 A`。
- 表格会被拆成多段：表头、行标签、单元格各自成段，分别翻译即可，
  不要合并、不要补句号、不要改写成完整句子。
- 提示框标题：`Note` → `注意`，`TIP` → `提示`，`WARNING` → `警告`，
  `Definition` → `定义`，`Summary` → `小结`。

## 提交前自检

1. 段数与编号是否与输入完全一致。
2. 每段占位符的种类、数量、配对是否与原文对应；编号每段独立，不要跨段比较。
3. 是否还有整句英文没翻译（产品名、代码、URL 除外）。
4. 中英文之间是否都加了空格。
5. 是否误把 `###` 说明行写进了输出。

## 自检不通过时

- 用 `check --chunk N --fix` 自检；`--fix` 会自动删除重复段、删除越界段、按段号排序，
  并删除单独标记 `⟦n⟧` 后面多出来的 `⟦/n⟧`。
- 报 `segment markers` 且仍缺段时，按报错给出的 `insert between ... and ...`
  在指定位置插入，不要追加到文件末尾。
- 报 `kept the last copy of ambiguous seg N` 时，检查这一段；不确定就只重写这一段。
- 报 `placeholder mismatch` / `stray placeholder` / `not translated` /
  `missing space`：只改报错的那一段，不要通读或重写整块。`extra` 里的标记
  一律删除；成对的多余标记整对删除，不要通过改编号来修复。占位符编号每段独立，
  不要跨段比较，也不要为了全局唯一改编号。
- `edit` 返回 identical、找不到 oldString 或多处匹配：不要重试，直接 `write`
  覆盖整个分块。
- 同一段同一个错误连续 2 次自检仍出现，停止修改并回复失败原因；同一分块最多
  3 轮自检，仍不过就回复一行失败原因并结束。
